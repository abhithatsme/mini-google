1997 Architecture

1997 — KEYWORD MATCHING

Early search engines (like Lycos, WebCrawler, and early AltaVista) parsed web pages as isolated bags of words. They ranked pages primarily by how frequently a user's query appeared in the document text and HTML tags.

1 Web crawler collects page text into an inverted index
2 Query is matched against word count per document
3 Vulnerable: Spammers repeat keywords 50× to claim rank #1
1998 Architecture

1998 — LINK AUTHORITY (PAGERANK)

Larry Page and Sergey Brin modeled the web as a directed graph. A hyperlink from Page A to Page B represents a citation of trust. The random surfer simulates human browsing across this topology.

1 Graph topology constructed from all outbound hyperlinks
2 Surfer traverses links (85%) with occasional random jumps (15%)
3 Robust: Keyword spam without incoming links receives ~0% authority
